# config

Central index of my setup — Alfred workflows for now, macOS/iOS config to follow.

## Alfred Workflows

| Workflow | Keyword | Description |
|---|---|---|
| [Netlify for Alfred](https://github.com/aleksgorbenko/alfred-workflow-netlify) | `nf` | Browse Netlify sites: builds with pass/fail status, env vars, settings, trigger/cancel deploys |
| [WaniKani for Alfred](https://github.com/aleksgorbenko/alfred-workflow-wanikani) | `wk` | Lessons/reviews, level history, SRS stats, accuracy, leeches |
| [BunPro for Alfred](https://github.com/aleksgorbenko/alfred-workflow-bunpro) | `bp` | Search BunPro grammar points |
| [Nihongo for Alfred](https://github.com/aleksgorbenko/alfred-workflow-nihongo) | `bun`, `ji`, `co`, `pa`, `sent` | Japanese grammar, dictionary, conjugation, particles, kana, kanji, and sentence tools |
| [Discogs for Alfred](https://github.com/aleksgorbenko/alfred-workflow-discogs) | `dg` | Search releases/artists/labels/masters, drill into tracklists |
| [Bandcamp for Alfred](https://github.com/aleksgorbenko/alfred-workflow-bandcamp) | `bc` | Search bands/labels/albums/tracks, drill into tracklists |
| [2Do for Alfred](https://github.com/aleksgorbenko/alfred-workflow-2do) | — | Browse and edit 2Do tasks/lists |

Each repo ships its own `.alfredworkflow` release — see its README for install/setup.
